# Component Patterns — Rokupi

> Detailed anatomy and styling rules for UI components, derived from the Rokupi brand guidelines.

---

## Logo Usage

The logo is the most critical component of the brand identity.

### Proper Usage
- **On Light Backgrounds:** Use the Primary (Blue/Color) Logo on a white background for contrast and legibility.
- **On Dark Backgrounds:** Use the 100% White Logo on black or dark backgrounds.
- **On Imagery:** Use the White Logo on dark-toned images, and the Primary Logo on light-toned images to maintain contrast.

### Misuse (Red Flags)
- **DO NOT** rotate the logo.
- **DO NOT** stretch or distort the logo proportions.
- **DO NOT** add drop shadows to the logo.
- **DO NOT** use unapproved colors for the logo.
- **DO NOT** outline the logo.
- **DO NOT** change the logotype or substitute the font.

## Buttons & Interactive Elements

Because Rokupi uses the rounded **Fredoka** typeface, interactive components should complement this friendliness.

| Property | Value |
|----------|-------|
| Border radius | `8px` to `12px` (Soft rounded) |
| Border | None (rely on strong background color contrast) |
| Shadow | None (flat design) |
| Primary Action | `#0123FF` (Blue) or `#F40362` (Pink) |

---

## Typography Blocks

| Property | Value |
|----------|-------|
| Alignment | Left-aligned |
| Line Height | `1.4` (Auto-leading formula: Size + 40%) |
| Paragraph Margin | Bottom margin equal to line height |

Text blocks should never be centered if they span multiple lines, ensuring a constant visual starting point on the left.

---

## Physical to Digital Components

Rokupi translates physical retail elements (Signboards, Facades, Product Packaging) into digital space:

- **Cards/Products:** Emulate the clean, high-contrast look of the physical product packaging. Use white backgrounds for product cards to let the colorful products pop.
- **Banners/Signboards:** Treat hero sections like digital signboards—bold Blue or Pink backgrounds with high-contrast white text (Fredoka Semi Bold).
